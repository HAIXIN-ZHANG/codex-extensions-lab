# Contributing

Propose a concrete use case before adding an extension. Keep each skill or plugin independently understandable and document what it does, when to use it, prerequisites, installation, examples, and limitations.

Test changes in an appropriate Codex environment and report what was verified. Do not include secrets or copy third-party material without the right to redistribute it. New contributions are provided under the repository's MIT license unless explicitly agreed otherwise.

See [AGENTS.md](AGENTS.md) for the canonical English skill location, install/update boundaries and check commands. Update the catalog, relevant docs and [behavioral scenarios](evals/README.md) when behavior changes. Separate prepared scenarios from actual model runs, and proposed integrations from implemented functionality. Source adaptations need retained license/provenance; linking a research reference is not source reuse.
