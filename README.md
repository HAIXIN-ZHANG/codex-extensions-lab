# Codex Extensions Lab

An open-source collection of reusable Codex skills and, eventually, plugins. The repository is the source of truth for extensions that can be used across projects and restored in a new Codex environment.

## Status

This repository is being initialized. There are **no installable skills or plugins yet**. Each future extension will include its own purpose, requirements, installation steps, and usage examples.

## Structure

- `skills/` — independent, reusable Codex workflows.
- `plugins/` — space for future plugin packages.
- `docs/` — development and portability guidance.

See [the setup guide](docs/setup.md) for how to get started and [the contribution guide](CONTRIBUTING.md) for adding an extension.
