# Product workflow profile template

Optional private file: `extension-profiles/product-workflow.md` under `CODEX_HOME`, or `~/.codex/extension-profiles/product-workflow.md` when unset. This public template contains no user's preferences. Copy it outside the public repository and fill in only explicit choices. Installation of a skill does not create or replace a personal profile.

Use `confirmed`, `proposed` or `unset` labels; include scope so a project-specific choice does not become universal. Free-form Markdown is intentional: no parser or dependency is required. Remove irrelevant sections.
