# v0.1 review and v0.1.1 corrections

Reviewed baseline: `3205684`. Scope: all eight skill rules, installer, English persistence/audio/export, documentation and selected external references. Working tree was clean before review. This is the author's code/source review with executable regressions, not an independent human audit or a completed model-quality benchmark.

## Reproduced and corrected

| Issue | Observed failure | Correction and regression |
| --- | --- | --- |
| Selected export read unrelated audio | A missing audio file attached to an unselected lesson prevented export of a healthy selected lesson | Filter document IDs before loading audio. Regression creates unrelated missing media and exports the selected lesson successfully. |
| Rewritten chapter retained old read status | After marking a chapter read, saving changed Markdown left the new version marked read | Content revisions default to generated; prior read status remains in history. Explicit status is still possible when justified by user feedback. |
| Installer had no concurrent-run exclusion | An existing update lock did not prevent a second installation | Exclusive sibling lock, preflight within the lock, staging outside discovery, and owned-stage cleanup. A busy-installer regression verifies no target creation. Backups remain per skill, not an all-catalog transaction. |

The three affected cases failed before correction and pass afterwards. The complete executable suite now contains eleven tests. Repository metadata/link checks and full YAML parsing are separate checks. No new package dependency was required.

## Skill changes

Polish now explicitly supports natural/professional/concise modes, final `note:`/`备注：` preferences, exact preservation of work references/error text, and tidy grouping of dictated prose. These are product behaviors reviewed in DraftWise-AI, not a port of its API service. Prompt Rewriting's default copyable output no longer includes a redundant English heading. Product Spike has a small conditional evidence/validation reference rather than an additional mandatory workflow.

## Remaining limitations

- Sixteen synthetic behavioral scenarios now cover all skills, but no model outputs have been collected/scored in this review. Static conformance and helper unit tests do not establish consistent model behavior.
- Local plugin discovery, cross-account transitions and mobile playback remain client-specific validation work. The plugin has not become a remote service.
- Archive import still rejects same-ID differences, including sequential changes from another device; there is no lineage-aware merge yet. This is documented rather than advertised as automatic sync.
- Speech generation was verified in the preceding implementation run. This review reuses that evidence; it does not claim another naturalness or accent evaluation. The local speech backend remains macOS-only.
- Source-only third-party comparison is not installation, execution, a licensing audit or proof of maturity. See [comparison and DraftWise findings](../research/2026-11-16-ecosystem-review.md).

## Maintenance changes

Added root AGENTS guidance, architecture/data boundaries, a proposed roadmap, behavioral scenarios and a read-only CI job using pinned action commits. CI is designed to run the local checks; its actual hosted status must be reported separately after pushing. Public source remains separate from private profiles, trackers and learning records.
