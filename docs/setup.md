# Setup and portability

Clone this repository to work on the extensions:

```sh
git clone https://github.com/HAIXIN-ZHANG/codex-extensions-lab.git
cd codex-extensions-lab
```

There are no extensions to install yet. When a skill is published here, follow its README for its supported installation method and prerequisites. Codex's skill installer can install a skill from a GitHub repository path; check the current Codex documentation and the skill's instructions for the exact steps. Restart or start a new session if required by your Codex environment.

The repository does not transfer account permissions, external-service connections, credentials, or local dependencies. A new account or machine may require separate setup and authorization. Never commit secrets, tokens, private transcripts, or personal data.

Plugin packaging and installation instructions will be added when a real plugin has been implemented and tested against the relevant Codex version.
