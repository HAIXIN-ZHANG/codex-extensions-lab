# Security reports and private data

Do not include credentials, job application records, private research, private learning archives, voice samples or personal profiles in public issues or this repository. The owner's explicitly published [English learning notes](plugins/skilldock-english/learning-records/README.md) are a separate, curated collection; their publication does not authorize copying private archives or another person's information. If a problem could expose data, use GitHub private vulnerability reporting when enabled; otherwise contact the repository owner through a verified private channel. This project does not promise a response SLA.

Local helpers run with the user's filesystem permissions. Review skill updates before use, keep backups of private records, and grant only the access needed for the current task. Browser, account and cloud integrations retain their own permissions. Exported HTML and JSON contain personal study data even when they work offline.
